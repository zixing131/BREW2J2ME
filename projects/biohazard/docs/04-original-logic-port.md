## 证据与复现

`bin.dat` 解压得到 171828 字节 ARM 镜像。`tools/reverse/make_analysis_elf.py` 仅为镜像添加分析用 ELF 外壳，虚拟基址设为 0。本文地址都是**解压镜像偏移**，不是原手机的运行时加载地址。原文件只读。

本机 IDA 9.2 / Hex-Rays 导出 380 个函数的 C 和 ARM 汇编到 `reverse/decompiled/`；`functions.json` 记录地址和调用者；分析数据库为 `game-analysis.i64`，日志为 `ida-export.log`。反编译器的类型与调用约定不完全可靠，关键计算以汇编和原 ARM 执行为准。

`j2me/tools/reverse/arm_oracle.py` 使用 Unicorn 直接执行原镜像函数，准备内存和寄存器后读取输出。没有用 Java 算法生成期望值，也没有替换被测函数。种子 2211133；镜像 SHA256、数量见 `reverse/arm-oracle.json`。fixtures 已保留，普通构建测试不依赖 Unicorn/IDA。

```sh
python3 j2me/build.py
python3 j2me/test.py
# 可选：从原 ARM 重新生成期望数据，需要 Python unicorn
python3 j2me/tools/reverse/arm_oracle.py
# 导出原剧情/文本供审阅
python3 j2me/tools/reverse/export_script_data.py
```

## 关卡结构纠正

520xx 不是可直接用来渲染的 byte 墙格子表。顺序为：

1. 28 B 头：width/height=u16@0/2，preCount=u32@24；随后 preCount×16 B。
2. u32 调色/混合描述数量，再跟每项 u32。图层 byte 是此表索引，不是图像 ID。
3. width×height 第一层；header[9]!=0 时有同尺寸第二层。
4. 始终存在 width×height 碰撞源掩码；每格展开成 2×2 个 16 单位碰撞格。
5. 四个 u32 数量，随后记录长度依次为 **12、8、12、20 字节**。

第一关 52000：60×30，944 条墙面、93 条对象、69 条盒体、30 条实体，总长 19076 B。盒体和实体反编译指针是 uint16_t* +=6/10，不能误当成 6/10 字节。全部 16 关均无未消费尾部。

51000：地面图集 ID1000；78×36 B 精灵、7×32 B 盒体、37×84 B 实体、13×116 B 效果描述；墙纹理起始 ID1101，52×16 B 墙面组合描述。盒体生成四个旋转墙面的代码在 0x18B5C，尚未接入当前绘制器。

## 移动规则

玩家占用位 8，实体位 4；正常阻塞掩码 13，玩家隐身路径为 1。移动前清除旧的自身 2×2 占用，移动后登记新占用。位置限制为 [16,width×32−17] / [16,height×32−17]。滑角含四角、相邻格与角度区间判断，不是碰墙就取消，已完整移植该函数。

方向优先级来自顺序覆盖：8 > 4 > 2 > 1；先移动后转向，左转优先于右转。Java 暂以 50 ms 调度一次；尚未证明与原 BREW 定时器的墙钟速度一致。

## 原剧情解释

110xx：u16 事件数、每事件 8 B 区域矩形，之后每事件 16 B 头和命令数×32 B 命令。每命令为 8 个 int32。可读导出：`reverse/scripts.json`、`reverse/texts.json`。

当前解释器分支：1 变量赋值/加减（byte 溢出）；2 对白；3/4/12 条件链；7 自动行走；9 淡入淡出计时；17 遮罩设置；19 定向旋转；23 保存提示边界；51 换关请求。自动触发的两个条件索引为 signed byte；负值跳过检查，非负索引要求变量非零。

开场直接执行 11000 的事件 0：

- 从 (80,848,0) 出发；原对白 ID 顺序为 6018,6021,6022,6023,6024,6025,6026,6027,6028,6030,6031,6032,6300,6301,6033。
- 按原命令旋转/插值行走，最终 (912,80,270)；变量 0、21、22 均设为 1。
- 末尾阻塞动作为保存提示。原输入 0x1F35C 有确认/取消路径，保存调用 0x11B3C。本版仅提供取消保存继续，**不会假装保存成功**。
- 集成测试即时确认对白、取消保存，309 个逻辑 tick 完成；不是玩家阅读时间，也未验证原滚动字幕计时。

0x1F908 的旋转反编译把目标角度和除法余数混淆；0x1F9CC 调用 0x104 后实际存入 R1（余数），每步转 10 度，不是瞬移到目标。0x104 的商是带符号截断除法。自动行走从 frame=0 开始，在 frame==duration+1 时结束。差分测试覆盖这些细节。

已识别但未移植的副作用命令 0/16/38/50 会显示事件、命令和 opcode 并停止，不跳过发武器/切状态/结局。原分发表自己忽略的其他 opcode 仍按原行为忽略。拿消防斧时到达命令16，所以本版**不能通关第一关**。

## 文本与字库纠错

ID0：526 个 ID，结束偏移表 @2108，第一段起点 4212，首个结束偏移 4260。误作开始偏移会让所有文字错位一条。确认键提示是 **5000**；开始游戏 **8900**；瑞克 **6020**。

ID10000：916 个字形；@4 的 256 个 u16 是按 Unicode 低字节分桶的数量，不是 ASCII 宽度。@516 是 916 组 (u16 codepoint,u16 slot)；位图起点4180。中文每字24 B、12行，**每行两字节按大端解释，bit15在左**；索引仍是小端。ASCII 基址26164，每字12 B、6×12；中文 advance=12。

原文的 $T 五位标志、$H/$L/$S/$B 六位 RGB888、$n/$N 换行不是可见文字。当前实现主色、描边和换行；完整渐变等效果待移植。原字库不含开发说明全部用字，诊断提示用 ASCII，原菜单/剧情保留中文。
