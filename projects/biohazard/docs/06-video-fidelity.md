## 相机与物体比例

此前 Java 渲染器采用通用的 `width / 1.32` 焦距、48 单位眼高，以及居中的视平线。
这些参数没有原程序依据，会改变视野、地面比例和敌人大小。

已从原程序确认：

- `0x17858`：眼高 210、焦距 170、垂直偏移 `200 - (viewHeight >> 1)`、远裁剪 1000。
- `0x4F8C`：地图坐标与墙高在投影前乘 4，因此 Java 地图单位下眼高是 52.5。
- 原生 176×173 世界视口的视平线为 77；焦距 170，而非此前的约 133。
- `0x21FB4`、`0x6640`：天花板高度取关卡头第 11 字节乘 32；地板与天花板到眼睛的距离不同。
- `0x48A0`、`0x9990`：精灵缩放使用描述符第 6 字节、到相机的径向距离以及独立锚点。
- `0x1E204`：开火动作的第 3 个 short 是相机沿朝向后移的距离，仅影响绘制，不修改玩家位置。

实际执行原 ARM `0x17858`（Unicorn）得到：

| 视口高 | 眼高 | 焦距 | 垂直偏移 | 远裁剪 |
| --- | --- | --- | --- | --- |
| 173 | 210 | 170 | 114 | 1000 |
| 193 | 210 | 170 | 104 | 1000 |
| 273 | 210 | 170 | 64 | 1000 |

进一步核对 `0x17200` 与随包 `biohazard.bin`：原作基准为 176×220，但会取实际屏幕尺寸自适配，且焦距仍为 170。不能把 240×320 的焦距再乘 240/176。
`OriginalCamera` 因此在逻辑视口保留固定焦距，额外分辨率显示更多场景；高分辨率的像素放大统一由 Canvas 做整数缩放。

## 原始界面资源驱动

`OriginalAnimation` 按 `0x193E0` 解析资源 20000 的 8 组动画，每帧包含 24 字节的控件记录。`0x1CE08` 规定底部居中锚点、独立 X/Y 百分比缩放和水平/垂直翻转。

- 动画 7 / 帧 0 包含两份封面 5045：顶部正常、下方垂直翻转。这解释了 240×320 截图里的倒影，并非需要补画背景。
- 动画 6 / 帧 0、1 恢复原主菜单和选中偏移（素材左移 13，文字左移 12），位置按 `0xEDD4`。
- 动画 3 恢复 HUD、原武器图标映射/缩放、四个快捷按钮；数值位置依据 `0x77C4`。雷达圆形裁切与旋转依据 `0xA7E8`。
- 图像 4301 / 4302 的三个状态恢复绿色/黄色/红色瞄准；宽度取武器瞄准角，锁定位置跟随敌人。
- 动画 1、2 恢复短代商场、超级枪械和随身商店。短代商场按 `0x1627C` 显示六个分类，超级枪械进入五种武器子菜单；不再把 12 条收费资源平铺成菜单。
- 商店显示行数、描述区、确认/返回和箭头采用 `0x8164`、`0xC144` 的布局。离线领取适配仍然保留，不发送收费短信。
- `0xD7A8` 的消防斧挥击缩放也已接入。

## 射击事件

Canvas 原先在每个 50ms 更新中重复调用 `fire()`，会把一次按住狙击键变成开镜后马上射击。现在只在新的按下事件请求射击；命中后连续攻击仍由原 `OriginalCombat.fireRequested` 状态机决定，不被适配层覆盖。新增生产 Canvas 回归验证一次长按仅开镜、第二次按下才射击。

同时按 `0xD7A8` 恢复开镜时半径80的黑色遮罩和原4304准镜图像；狙击枪未开镜时不绘制普通武器的括号准星。

## 材质与雷达

- `0x235F4` 的四方向线性、四角径向、四角反向蒙版已移植，保留 RGB565 整数截断、叠加贴图、局部阴影及整块半亮规则。
- 新的 `material_oracle.py` 实际执行该原 ARM 函数，只适配 malloc/free、memcpy 和资源查询；27张32×32结果作为独立期望，Java逐像素相等（27,648像素）。测试不使用Java结果生成期望。
- 按 `0x21FB4` 接入关卡雾色、雾起点和密度；灯光贴图7—10的常亮/闪烁标志来自 `0x6640`。墙和精灵的雾采样仍是Java深度计算，不能据材质一致推断整帧完全一致。
- 雷达增加原出口、区域目的地和剧情目标，坐标直接来自 ARM `0x270F0`、`0x27170`、`0x271B0`，204个分量与原数据逐项对照。标记使用原2102—2104图像；屏外半透明效果仍有差异。

## 验证结果与边界

原 ARM 逻辑差分测试与 Java 渲染截图是两种不同证据。桌面 Canvas 测试运行生产绘制和输入代码，但使用 MIDP/RMS 适配器，不能代替真机性能测试。
通过五分辨率菜单/世界/商店截图与生产Canvas输入测试；240×320、320×240触摸默认关闭，360×640默认开启的规则未改变。原有存档、战斗、剧情和16关加载测试继续通过。0.3.2 JAR经过ProGuard CLDC预校验。

目前仍须继续核对对话、枪口特效、室外天空、音效以及全流程节奏。视频仍受登录浮层阻挡，没有看完后半段，不能据这些修正宣称体验已经完全一致。
