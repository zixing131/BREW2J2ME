# 0.3.8 中文界面、安装图标与商城

## 图标来源与兼容性

原输入`originals/1073745158.mif`在偏移140内嵌26×26、24位、未压缩BMP，偏移2288还有16×16小图标。构建读取主图标，处理BMP倒序行和每行补齐后生成`resources/icon.png`，不重画原作图标，不改动输入文件。

JAR Manifest和JAD均设置`MIDlet-Icon: /icon.png`，`MIDlet-1`同时提供中文入口名与图标路径。套件级`MIDlet-Name`和Vendor保留原值，避免改动升级时的应用标识；入口类、RMS名称和存档版本均保持。测试验证图标尺寸、源像素及两份元数据，PNG总数由210变为211。

## 界面调整

生产入口为`OriginalCanvas`，历史演示不在本次界面范围内。复用原图像5006标题金属构件、5012对话面板、5014按钮、5002选中边框以及枪械图标，面板保留边角尺寸，仅延展内部。系统、记录、背包、改装和设置页都有标题、状态、副说明及底部操作按钮；主菜单、世界HUD和剧情对白继续使用原布局。

存档列表分两行显示记录名/关卡、生命/时间；空位显示“未保存”。帮助、关于和购买说明支持滚动，覆盖记录和剧情确认使用统一面板。触控按钮及错误/购买/存档反馈改为中文，不直接把Java异常消息显示给玩家。GPS和MB系列枪名保留原资源命名。

新增中文受原12像素位图字库约束，测试逐字检查界面、记录描述、购买反馈中的中文，避免缺字退化为省略号。各菜单同一套行位置用于绘制和命中；测试检查标题、列表、底部操作区不重叠。继续保持240×320/320×240触控默认关闭、360×640默认开启。

## 六类商城与离线购买规则

原`0x1627C`生成六个顶层分类：第一个进入五把超级枪械，其余分别映射商品表0—4。资源15000的记录5/6是原地复活与正版验证，不是额外金钱档位，不加入截图中的六类菜单。

| 分类 | 生效内容 | 本版购买行为 |
| --- | --- | --- |
| 超级枪械 | 原武器ID9—13，五项最高改装，自动装备 | 五把均可购买；可重新选购曾使用的枪，沿用单个超级武器槽 |
| 超级弹药 | 原无限储备状态和购买记录 | 一次生效，重复操作显示已购买 |
| 超级隐身 | 每次增加1份隐身能源 | 可重复购买，在系统菜单开启 |
| 超级生命 | 最大生命翻倍、恢复至新上限 | 可重复购买，保留存档可表示范围上限 |
| GPS地图 | 开启地图权限 | 一次生效，数字键9打开 |
| 兑换金钱 | 每次增加5000游戏金钱 | 可重复购买，整数溢出前停止 |

道具效果依据`0x1293C`和原商品表。原`0x13EDC`在短信购买流程检查表`+6`及变量计数；旧移植又使用全局累计计数直接拒绝复购。按用户要求，**本版离线商城调整了复购限制**，不是声称与原付费流程逐指令等价。永久弹药/GPS不重复授予，隐身/生命/金钱和武器替换可复购；失败会显示具体中文原因，成功后返回原选中分类并尝试自动保存。

超级弹药广告文字提到无需操心装填，但原`0x20458`在玩家`+33`启用时仍补满弹匣并启动原装填计时；这里保持现有原战斗语义，没有因为广告文案把所有枪改成无装填。武器本身`weapon[6]`的无限射击标志仍独立处理。

## 验证

`python3 tools/project.py test biohazard`完成构建和全套回归。7项资源/字库测试、153,814项原系统断言、572项生产Canvas/RMS断言通过；ARM差分、16关加载/存档往返和损坏回退继续通过。

新增购买测试通过生产界面依次购买五类道具、五把枪，验证实际属性、重复购买、已拥有反馈、重新装备及RMS自动存档恢复；触屏确认购买也执行同一路径。176×220、240×320、320×240、360×640、640×360均生成系统、记录、装备、改装、设置、帮助、关于、覆盖和购买预览，并检查绘制/点击行坐标一致。

人工查看小屏系统菜单、横屏记录列表、高分辨率覆盖确认、武器改装及购买提示。预览位于忽略的`j2me/build/ui-previews/`，来自生产Canvas桌面适配器，不宣称是手机安装或整关实测。0.3.8产物经过CLDC预校验，JAR/JAD大小、class major45、StackMap和图标资源检查通过。
