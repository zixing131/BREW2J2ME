# 地下城与勇士：鬼剑士 — WIPI → J2ME

原版为韩国 LGT WIPI Clet，名称 `던전앤파이터 귀검사`，NexonMobile，版本 01.00.00。`0002E1A1.jar` 是资源归档，程序主体是 ARM `binary.mod`，没有 Java class，不能直接换 JAD 运行。

目前为 **0.8.0 职业与状态机制阶段版，尚非原版等价的最终版**。装备、原材料掉落与363条配方、城镇交易、69个主线节点及原结局链已经接通，中文使用设备原生字体。

本版开放原四职业/觉醒技能目录、学习与快捷键绑定、40个职业委托、原职业属性成长；增加附加伤害与异常状态、召唤/治疗/增益/光环/瞬移行为，以及两个持续技能共存和完整中途存档。新增职业试炼入口和死亡之塔逐层进度，当前共25个地下城入口。**目录完整不代表高级技能特殊行为全部恢复**，卡洛、狂暴普攻、蓄力/刻印、部分被动和首领控制器仍有缺口；见[0.8证据、验证及未完成项](docs/10-professions-status-bosses.md)。

```sh
# 仓库根目录
python3 tools/project.py verify-inputs dnf
python3 tools/project.py test dnf
```

发布文件为 `j2me/dist/DnfGhostKnight.jar` 和配套 JAD，由 ProGuard `-microedition` 完成 CLDC 预校验。

## 正常入口

原标题画面（DAT45223）→确认→四个记录槽。左右选槽，空槽确认开始新游戏，已有记录确认续看；`*` 删除重开，默认选择“否”。新游戏入口来自原程序 `0x1700`：100 → 101 → 102 → 103 → 999 → 201 → 3 → 4。剧情4结束进入41/2研究室，走近标有“研究日志”的书桌按5交互；确认后进入剧情5和首波战斗。清场后接续6/7与德林保护战，完成后播放8/9/10/11并进入斯顿雪域。

剧情中5推进对白，0保存返回；高分辨率可以触摸正文继续、点击右上角保存返回。中文在场景缩放之后绘制，按设备字宽分页。战斗中5攻击/连击，1/3使用绑定技能（初始上挑/鬼斩；德林阶段为其原绑定技能），7任务手册，9背包/商店/合成/地下城/技能修炼，0菜单；双击左右可冲刺。冒险手册可保存、查看任务和回城休整。四槽保存本移植版的剧情和战斗状态，尚不兼容原版DnfHero/DnfQuest文件。

## 开发浏览入口

标题按 `#` 打开开发菜单：场景与动作试玩、原版剧情全档、中文日记、原音乐/音效试听、设置等。这些浏览功能不代表解锁了主线内容。场景里方向移动、5挥剑/连段、1/3查看动作、*菜单。独立试玩记录与开场记录互不覆盖。

240×320、320×240默认关闭触屏操作；较高分辨率默认开启。触屏控制条在试玩和战斗场景出现，剧情与日记使用原生文字界面。设置可覆盖触屏默认值，并保存音量与动画速度。

声音全部来自原包：采样转换为WAV，乐曲转换为MIDI，挥剑声由原动作帧的反应表触发。Yamaha专用FM音色尚未复刻，设备GM音源会影响听感。汉化覆盖ANI对白/演出文本和日记；已接入的主线NPC委托也有中文；部分装备专名、支线文字和图片内韩文尚未全部汉化。
