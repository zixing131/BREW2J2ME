# 地下城与勇士：鬼剑士 — WIPI → J2ME

原版为韩国 LGT WIPI Clet，名称 `던전앤파이터 귀검사`，NexonMobile，版本 01.00.00。`0002E1A1.jar` 是资源归档，程序主体是 ARM `binary.mod`，没有 Java class，不能直接换 JAD 运行。

目前为 **0.2.0 剧情、汉化与声音移植版，尚非完整主线游戏**。按原数据解释63段剧情、30篇日记、46轨声音；669条去重文本已汉化，中文由设备原生字体绘制。原地图、动作及部分时间轴状态经过原ARM程序核验。敌人AI、伤害结算、物品、任务条件仍待接入。

```sh
# 仓库根目录
python3 tools/project.py verify-inputs dnf
python3 tools/project.py test dnf
```

发布文件为 `j2me/dist/DnfGhostKnight.jar` 和配套 JAD，由 ProGuard `-microedition` 完成 CLDC 预校验。

## 正常入口

原标题画面（DAT45223）→确认→四个记录槽。左右选槽，空槽确认开始新游戏，已有记录确认续看；`*` 删除重开，默认选择“否”。新游戏入口来自原程序 `0x1700`：100 → 101 → 102 → 103 → 999 → 201 → 3 → 4。剧情4的结束分支应进入关卡，当前在这里保存并明确提示后续关卡未移植，**不会把它错误连到剧情5**。

剧情中5推进对白，0保存返回；高分辨率可以触摸正文继续、点击右上角保存返回。中文在场景缩放之后绘制，按设备字宽分页。四槽保存的是本移植版的开场进度，尚非原版角色/任务存档。

## 开发浏览入口

标题按 `#` 打开开发菜单：场景与动作试玩、原版剧情全档、中文日记、原音乐/音效试听、设置等。这些浏览功能不代表解锁了主线内容。场景里方向移动、5挥剑/连段、1/3查看动作、*菜单。独立试玩记录与开场记录互不覆盖。

240×320、320×240默认关闭触屏操作；较高分辨率默认开启。触屏控制条只在场景试玩出现，剧情与日记使用原生文字界面。设置可覆盖触屏默认值，并保存音量与动画速度。

声音全部来自原包：采样转换为WAV，乐曲转换为MIDI，挥剑声由原动作帧的反应表触发。Yamaha专用FM音色尚未复刻，设备GM音源会影响听感。汉化覆盖ANI对白/演出文本和日记；尚未接入的NPC/任务文字、图片内韩文不在本轮覆盖范围。
