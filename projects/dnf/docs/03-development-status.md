# 开发状态

## 0.1.0（2026-10-26）

可运行的场景与动作试玩，**尚非完整游戏**。

已实现：原包只读解压；DAT/FRA/ACT解释；RGB565透明色、精灵拼合、镜像旋转与混合；原动画逐tick推进；169个原地图的远景/地面/装饰；20组主角外观；移动和三段挥剑演示；中文适配菜单/图标；四槽试玩RMS；240×320、320×240、360×640、640×360显示与触屏默认值。

当前用户可验证第一阶段移植可行性。下一阶段恢复剧情、对话、场景事件和原音频，再将敌人/伤害/物品/任务/原存档结构接入。场景浏览不是剧情进度，挥剑动作不是已完成战斗，换外观也不是完整职业装备系统。

## 构建/测试

根目录 `python3 tools/project.py test dnf` 会校验原输入、重建资源、编译、预校验并运行测试。需要JDK7、CLDC/MIDP API、ProGuard，配置复用根toolchain。

`python3 projects/dnf/j2me/tools/reverse/native_oracle.py` 仅用于显式重建ARM基线，需要Unicorn；普通测试不运行此脚本。fixtures来源与原程序哈希保存在 `tests/fixtures/provenance.json`。更改期望值必须说明原函数或输入变化。
