# 0.4.0：城镇任务与首个地下城

这一版接通开场后的实际游玩：斯顿雪域 → 赫顿玛尔街区 → 玛丽/风振/G.S.D/林纳斯的初期委托 → 幽暗密林普通难度 → 多房间战斗 → 牛头巨兽 → 回城。它是可持续游玩的首个地下城里程碑，**不是全部530任务、全部职业和装备系统移植完成**。

## 原数据依据

- `659a8`：DS type1出口须先离开矩形才激活；城镇 zone0/20 可以直接切图，地下城须清场。目标 field/stage、目标入口编号取 DS 记录；雪域79/1出口连接1/1，再连接0/1。1/1为北街，3/1为南街；0/1的西侧type3/mode2区域打开地下城入口。
- `2b6b4`：入口编号200使用ZON出生点，普通编号查目标DS area.index，使用矩形中心。Java额外对中心落在不可站立碰撞格的情况，在32像素范围内找最近可站立点；这是移植碰撞层的防卡死处理。
- `2b8e0`：ZON前三字节为rows/cols/flags，然后三组候选。每组有entry/boss/special三项，每项两个u8坐标；均非255时再读取u16 field/u8 stage，随后s16 x/y出生点；末尾rows×cols网格。46份文件均精确消费到EOF。1.zon第一组入口6/1、(34,205)，首领10/1；第二组6/2、(484,213)，首领10/2。
- `2112c`：quest以LE u16数量起始，每条225字节。条件165起三项`BBHB`；目标180起三项`BHHB`；奖励198为u32经验、202为u32金币，206为额外字段。**不是经验/金币反过来**。`3a264`把memory+216传给`7cf20`加经验，memory+220加到角色+24金币。
- `20ebc`：npcInfo的8个地图记录与39个NPC记录按原loader读取；每NPC的提供/交付任务是普通LE u16列表，不是带高位标记的特殊整数。地图0/1的NPC0才是风振，不是25。
- `1fa10`：条件1按任务状态比较（0未接、1进行、2完成），条件2按等级下限比较。本轮只开放已翻译且目标可执行的2、3、4、7、8；未理解的条件不放行。
- `1fef4`：击杀目标类型3中的怪物编号为零基，须加1后与实体monster ID比较；末字节6表示不限制难度。任务7是monster7×10，任务8是monster10×4，计数封顶；不是根据画面外观把所有哥布林都计入。
- `8a400`：普通难度、无装备加成时，死亡后经验为怪物等级×类别系数。原text `9d0f8`三个系数为5/6/10，类别来自6.bd record+29；普通难度data `1401e3e`的经验倍率与附加值为0。角色等级高于怪物超过10时经验除5。教学战斗继续跳过一般击杀奖励，以开场任务完成奖励进入后续成长。任务0/1的完成时机及旧档补发仍按开场适配检查点处理，尚未证明与原任务控制器的逐步奖励时机一致。
- `7cf20`：升级门槛为`230*level^3/100 + 700*level`，单次经验授予至多升一级，超过下一门槛的余量封顶到门槛-1。现仅接经验/等级及升级补满当前HP/MP，技能点、完整成长属性与装备修正尚未接齐。

## 游玩、恢复与记录

5攻击/连击或附近交谈；1上挑、3鬼斩；7任务手册；0打开冒险手册，含继续、保存、保存回标题、任务与角色、回城休整。高分辨率通过触屏菜单打开任务手册。NPC与出口显示中文悬浮提示；入口需要确认。清场前出口封锁，清场后通过原DS连接行进；死亡动画结束才记经验与击杀数。

同一轮地下城已清房间记在Campaign，回头不重生、不重复发经验。完整清关或主动撤退后结束此轮，再进地下城刷新。死亡后5返回城镇，保留已经取得的经验与任务进度并补满HP/MP；这是防止试玩卡死的恢复适配，未复刻原复活币/死亡惩罚。城镇菜单可休整。

DNB2新增独立Campaign：任务状态、计数、经验、等级、金币、回城位置、地下城/首领信息、已清房间、通关次数及当前NPC对话/待执行动作。DNS3把同一Campaign与剧情记录存进**同一个RMS record**，避免先写任务后写剧情导致状态撕裂；整体校验。DNB1、DNS1/2继续可读；旧雪域记录补齐开场任务检查点。保存清场结算对话后重读不会再加通关次数。失焦/正常退出与原四槽逻辑保留。

## 已验证与仍有区别

- `tools/reverse/campaign_oracle.py`执行原ARM quest/NPC loader和条件函数：核对530条记录的条件、目标、奖励内存布局，导出39个NPC及40组条件结果，普通测试读取提交的fixture。不是仅用两个自写解析器互相证明。
- CampaignTest通过真实方向/攻击输入从雪域出生点行走到三个任务联系人，再进入首个地下城，逐房间战斗到首领并回城；不改玩家位置或敌人HP来代替这段流程。首轮正常成长到等级3后，再从风振/G.S.D接受击杀委托，第二轮真实战斗完成两项计数并返回交付。另测返回已清房间、任务不重复领奖、计数封顶、死亡恢复、坏档拒绝和DNB1迁移。死亡/封顶专项测试使用明确构造的状态。
- Canvas/RMS四分辨率覆盖玛丽多页对白、任务确认→ANI12→保存重读→继续任务、任务手册、地下城续玩和失败回城，并生成截图。桌面适配测试与真实MIDP设备性能/声音验证有区别。
- 目前固定使用ZON第一组出生点；首个地下城两条原DS分支都能走，两组ZON首领房均可结算。原随机布局/网格封路、难度选择和全区域解锁未还原，不能称完整ZON调度等价。
- 仍有缺口：林纳斯材料/合成任务5/6和后续主线、物品/掉落/背包/商店、任务2装备奖励、完整属性/伤害/AI、更多技能及日记解锁。初始HP/MP仍为100；高级任务不显示为可接，避免给出无法完成的委托。
