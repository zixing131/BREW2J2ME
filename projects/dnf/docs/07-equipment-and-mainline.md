# 0.5：装备、掉落、合成、商店与后续主线

这是可运行的主线系统扩展，不是原版逐项等价的最终版。下面分别记录原始依据、当前实现和未完成项，避免把“数据可读”或“状态测试通过”误称为完整通关。

药品文件中效果从偏移8开始，参数是偏移9的小端u16；原程序将紧凑记录展开后从效果内存结构+2读取参数。固定值和百分比恢复上限均为角色最大值。特殊持续恢复、异常状态、随机效果和部分模式专用效果尚未恢复，不消耗这类道具；商店不出售无有效恢复参数或尚不支持的药品。原药品公共冷却尚未确认，当前没有宣称还原冷却。

## 玩法连接

正常流程继续使用原NPC交谈与目标。9打开背包，1/3切换背包、商店、林纳斯合成、地下城、主线导航；上下选择，5先查看再确认，#出售或切换地下城难度，0返回。主线导航提供地点和进度，接取与交付仍需走到NPC前交谈。低分辨率默认无触屏按键，高分辨率使用触摸入口。

- 八个装备槽保存原物品身份。等级不足不能装备，已装备物品不能直接出售。武器攻击、防具防御及部分附加属性参与战斗。
- 合成、购买、出售、任务交付均先检查再扣除。四选一任务奖励支持1/3或屏幕底部左右区域切换，选择在读档后保留。
- 地面物品接近后拾取，满容量时保留；任务道具按原流程直接进背包。保留掉落随机数状态、未拾取物品、当前地下城难度和计时。
- 69个主线节点与辅助任务7/8/213接入，覆盖格兰之森、天空之城、贝希摩斯、雪域和决战。22个地下城根据主线逐步解锁。
- 克莱尔护送具有跟随、受伤、失败和完成条件；现阶段的跟随AI、生命值与绘制仍为适配行为。
- 最终事件使用原47→48→481→482→483链，回到雪域后选择并领取任务259的奖励；最终战要求按原任务数据完成对应难度目标。

## 状态与架构

`Items`只负责原物品/配方与中文目录；`Inventory`负责数量、装备与交易事务；`Loot`负责原掉落表和地面物品；`Adventure`负责主线区域列表及mapAni条件；`GameMenu`是不依赖MIDP的菜单模型。`DnfCanvas`只做输入、设备字体分页及绘制；`Battle`持有同一份`Campaign`，贯穿城镇、战斗和剧情。

Campaign内部格式升级到2，保存背包、装备、掉落、难度/计时、护送、已播事件和奖励选择。仍读取正式发布的0.4 Campaign v1；迁移时补回已完成任务原本未入包的物品奖励，多选项按第一项补回（旧记录没有选择信息）。这不是原WIPI存档格式兼容。

战斗外层仍为DNB2；剧情记录新增DNS4，包含Campaign和被演出暂停的完整战斗状态。保留DNS1/2/3与DNB1读取。剧情回到同房间时复用房间，不能重新生成敌人、重置血量或重置计时。DNS4使退出游戏后也保留这个行为。

`localization/sc-zh-CN.json`使用`任务:接取或交付:NPC`键。构建从原SC定位对应序列，核对完整key集合、每段行数、说话人和事件；对白在交谈时按需读取，不把全部对白常驻CLDC堆。`monsters-zh-CN.json`按原文名覆盖全部怪物；`items-zh-CN.json`覆盖已翻译专名。构建输出`build/item-text-audit.json`记录未翻译项，不把编号标签冒充汉化。

## 尚未达到原版等价的部分

1. 转职、完整技能树/被动、各首领专属AI、全部受击状态与物理/魔法伤害公式；当前基础伤害和部分成长存在适配项，基础HP/MP还保留最低100的兼容值。
2. 商店使用原标价，但商品集合、等级筛选和出售四分之一价格尚未证实为原规则；随机装备强化/词缀、附魔和罐子未完成。
3. 部分装备专名、非主线支线及NPC普通闲谈仍未汉化/开放。当前不是530条任务全部可玩。
4. 原ZON随机布局、封路规则未完全恢复；当前选择第一候选入口并开放有效DS分支。
5. 药品公共冷却、特殊道具、各地图BGM调度、Yamaha音色、全演出像素等价与真机性能仍待恢复/核验。

这些是后续必须收敛的工作，不应把0.5命名为“最终完整版”。
