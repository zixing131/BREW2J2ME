# 0.6：原版对照与规则修复

本轮以原WIPI ARM程序和资源表为依据。当前可玩流程并不等同于原版完全还原，尤其不能把69个主线节点的事务测试当作人工全剧情通关。

## 已确认并修复的差异

| 项目 | 0.5行为 | 0.6及原始依据 |
| --- | --- | --- |
| 场景音乐 | 战斗继续使用上一段剧情音乐 | 执行原`0x39724`核验：赫顿玛尔13、西海岸14、雪域15；地下城普通房`2*group+14`、首领房`2*group+15`，group7首领为26，特殊房27 |
| 地区模式 | 所有地下城固定mode2 | 按原`0x1402042`的8×10区域表恢复；森林2、天空之城3、贝希摩斯4、雪域/最终区域5等 |
| 播放生命周期 | 进房、回城与剧情返回未重选音乐 | 进房/首领/回城切换；同曲连续移动不重新播放；剧情返回、RMS恢复都重新选择正确曲目 |
| 基础成长 | HP/MP至少100 | 原`0x1402fa4`、`0x79e14/0x79c88`：未转职无加成时HP=31×等级，MP=16×等级+20；保留已支持装备体力/精神及HP/MP加成 |
| 祝福之石/魔力之石 | 无法使用 | 效果60/61，`0x79f7c/0x79de0`：永久增加最大HP/MP，不自动补满当前值；增加值取原道具参数 |
| 经验书 | 无法使用 | 效果119，`0x7d128→0x7cf20`：使用原经验参数和现有原阈值/单次最多升一级规则 |
| 命运硬币 | 无法使用 | 效果118，`0x7cc4c`：原13:26道具为50%恢复最大HP的30%，否则损失25%，可致死；满HP仍可使用，mode7禁用，教学免伤保留 |
| 存档 | 没有永久道具属性 | Campaign v3追加永久HP/MP，保持v1/v2读取，外层DNB2/DNS4不变；旧地下城mode2与旧背景音乐在载入时纠正 |

增长计算仅指当前未转职角色及已支持加成；完整职业被动、全部套装/百分比属性尚未等价。永久属性使用上限1,000,000防止存档整数溢出；满级不消耗经验书。这两项是移植端约束，不宣称来自原程序。

`FieldRules`集中保存可独立核验的区域、选曲、基础成长和硬币运算；`Battle`负责把房间和道具接入规则；`Campaign`保存永久结果；`DnfCanvas`同步MMAPI，原剧情音乐指令继续独立生效。原音频资源不变，没有用外部音轨替换。

## 可重复验证

显式运行`j2me/tools/reverse/field_rules_oracle.py`会执行原ARM函数，生成26组音乐、10组HP/MP成长和12组硬币结果。普通测试只读取提交的CSV，不重新生成期望值。`field-rules-provenance.json`记录原二进制哈希、区域表和替代调用：音乐设备调用被捕获；无已学技能时HP被动返回0；硬币随机数与伤害许可受控；选曲分支、成长计算、硬币分支和HP增减仍执行原ARM。

- 44,033核心、13,377剧情、640战斗、160城镇/地下城、737玩法检查通过。
- 665项生产Canvas/RMS检查覆盖240×320、320×240、360×640、640×360：中文道具详情/分页确认、永久效果保存、地区与首领选曲、同曲不重启、回城和读档。
- 首个完整地下城和第二轮击杀任务使用实际移动/攻击输入。测试角色装备真实任务奖励，用任务金币购买面包，并使用拥有的恢复品及鬼斩；没有为了恢复31/62点原始低等级HP而补造生命值、金币或伤害。
- 69节点全主线仍是目标注入后的事务验证，不是零作弊全程实战；22地下城入口与读档都核验，不能推断其全部首领战已人工验证。
- 已查看生产Canvas生成的240×320/320×240永久道具页面及360×640战斗图；中文未越界，小分辨率默认无虚拟键盘。桌面字体适配截图不代表所有手机的原生字体效果。
- 本轮未完成独立KEmulator窗口的人工操作/听感对照；MMAPI测试验证资源可读、生命周期和音轨选择，不宣称音色听感等价。
- 发布构建强制ProGuard `-microedition`；校验major45、CLDC StackMap、无StackMapTable、JAD尺寸匹配。

## 剩余差异与优先级

1. **战斗**：玩家伤害仍使用简化公式。已定位原固定物理`0x7c298`、固定魔法`0x7bf58`、武器百分比物理`0x7c8bc`、百分比魔法`0x7c544`及分派`0x7ed64`，但42字节技能表到运行时104字节槽的完整映射仍待核实，不能仅看某个字节猜物理/魔法。转职、完整技能树/被动、怪物专属AI、击退/异常状态和护送AI仍需恢复。
2. **特殊道具**：原效果106并非“普通持续回血”，`0x7cee0`在恢复HP后调用`0x38580`施加概率异常；107还会清除部分状态。暂不消耗这些未完整实现的道具。辅助药剂的持续时间/叠加、公共冷却、力量/智力石与SP书仍待接入；不把未知字段当作冷却秒数。
3. **地图与任务**：仍选ZON第一候选入口并允许有效DS分支；原随机布局、封路/门控未完整复刻。当前特殊房BGM对应已选第一候选路线，不能据此声称原全部随机路线已还原。530个任务只接入现有主线与少量辅助任务。
4. **经济和装备**：商品集合、等级筛选、出售四分之一价格属于适配规则；原NPC商店目录、词缀、强化、附魔和罐子未完成。部分装备专名、支线/NPC闲谈仍需汉化。
5. **呈现**：系统菜单/记录槽是中文适配样式；原全部界面动画、图内韩文、音乐淡入淡出/全局优先级、Yamaha FM音色、真机性能与全演出逐帧一致性仍待核验。

因此0.6是一轮有原程序对照的修正，不能标记为“近乎完美”或“最终原版等价版”。后续应优先完成技能数据加载和伤害/受击状态，再扩大后期实战验证。
