# 0.7：技能数据、伤害分支、落雷和随机入口

这版继续缩小与原版的差异，**没有完成全部职业技能和全部首领 AI**。以下严格区分原 ARM 已核验的计算、已接入玩法和仍使用的适配规则。

## 技能与成长

原 `0x2490c` 从 `(100 + skillId).bd` 读取 42 字节等级记录，展开到技能槽内 48 字节参数块。文件第 0 条是未学习预览；实际 1 级应读取第 1 条。此前把第 0 条当作基础参数，并把刺击编号 2 当作上挑。

| 内容 | 本版恢复与依据 |
| --- | --- |
| 默认技能 | `0x1400758` 的首两个绑定为 6、9，即上挑、鬼斩；动画表 `0x140306d` 对应动作 24、32 |
| 技能参数 | 全部 75 个编号、1,094 条有效等级记录：MP、冷却原值、学习等级、前置技能/等级、晶体数量、伤害类别、三段威力及三组附加效果均保留；不是将这些技能全部开放使用 |
| 伤害类型 | packed `+10` 是物理/魔法；三段 `+11+3*i` 为类型，0 是武器百分比，非 0 是固定伤害；`+12+3*i` 是小端威力 |
| 技能动作 | 普通角色上挑改为 `0.act:24 + 30024.act`；鬼斩改为 `0.act:32 + 30032.act:0`，不再共用上挑特效；德林保留 31/35 的已有动作绑定 |
| 技能点 | 执行 `0x7cf20` 核验随经验增长的 SP，含跨 17/18、39/40 级的配额切换和单次最多升级一级的余量行为 |
| 学习 | 城镇菜单新增“技能修炼”，开放上挑、鬼斩升级；等级需求取下一条等级记录，SP 成本取 `175.bd`，不足不扣费；技能等级写入存档 |
| 中文名称 | 按原 `0x1400388` 的 75 个名称编号本地化，包括派生技能与被动，避免名称错位 |
| 初始武器 | `0x34410` 的 `0x9670d/0x9670f` 表含物品 `(1,1)`；在开场结算补入并装备缺失的破旧太刀，已有武器不覆盖。补发时点是移植端衔接规则，不代表完整复制该初始化函数 |

SP 按每级配额 33（1–17）、36（18–39）、40（40+）分段。经验未升级时，步长为 `needed / quota + 1`，获得新旧经验整除该步长之差；升级时计算旧级剩余配额及新级经验部分。原程序对单次过大的经验奖励还有 byte/short 窄化行为，保留并通过 120 组 ARM 结果核对。

## 四条基础伤害分支

`CombatRules` 对应固定物理 `0x7c298`、固定魔法 `0x7bf58`、百分比物理 `0x7c8bc`、百分比魔法 `0x7c544`。普通无转职被动、无强化和暴击加成的分支：

- 固定：`威力 + 平坦攻击加成 + 属性 * 威力 / 200`。
- 武器百分比：`威力 * (武器攻击 + 平坦攻击加成) / 100 + 属性 / 2`。
- 防御减免：`max(1, 100 * 防御 / (80 * 敌人等级 + 150))`；物理用怪物记录 `+56`，魔法用 `+58`，此前只用了魔防。
- 先减防，再加平坦额外伤害，再按属性相克修正，最后加原武器等级决定的随机波动。每一步整数截断顺序保留。
- 两个固定分支在波动后窄化为 unsigned short；魔法百分比分支在波动前窄化；物理百分比不做该窄化。不能统一写成一个最后截断的公式。

原分派 `0x7ed64` 的攻击段编号从 **1** 开始。现在使用 ACT 的 `regionKind` 选择三段参数，而不是按某几个动作编号猜段数。装备物攻/魔攻、力量/智力与已支持的平坦加成接入；当前角色元素状态仍未恢复，运行时按无元素处理，纯函数的属性相克分支已独立核验。

这些是**基础伤害函数等价**，不是完整伤害流水线等价：命中、暴击、武器精通、强化、转职/套装/异常触发，以及敌人对玩家的完整伤害公式仍待接入。父亲阶段的完整装备和职业属性也未恢复，不能以基础函数对照替代该阶段的数值验证。

## 怪物与首领

`6.bd` 的 420 条怪物记录现在关联 `5.bd` 攻击距离、`7.bd` 行为描述和 `2.bd` 特效信息。

- `0x89e18` 按三个权重选择攻击槽；未落入任何权重时返回游走选择，修复沿用上一攻击槽的问题。后续游走/寻路仍是适配实现。
- `0x84374 → 0x81bb8` 的攻击距离来自 `5.bd`，包含不同的前后距离和地面纵深；镜像时交换方向。此前误用怪物记录 `+68/+69` 作为统一距离。对手可以先选择远程攻击，再进入其射程。
- 凯诺（怪物 25）的行为 5、4 为类型 0，关联原 `36000.act` 的动作 0、1。`0x8337c/0x832c8` 给出目标坐标、偏移和动画；已接入地面预兆、单道/连续落雷画面、原攻击帧碰撞、动作帧音效，以及保存后的逐 tick 续演。
- 原行为索引 255 仅表示没有附加行为，**普通攻击仍然有效**。牛头王萨乌塔（46）的行为 16 是类型 14，不能误做冲锋；其该附加状态尚未接入。
- 受击动作遵守已恢复的 boundsKind 条件，并保留首领动作 20 的不打断分支；其他霸体来源、浮空、击退及异常状态仍缺失。

落雷目前按一次施法对玩家一次命中处理；连续落雷的全部多段受击/免伤状态、护送单位与特效的完整交互，仍不等价。这里不把“看到首领特效”算作全部首领 AI 完成。

## 随机地图与存档

`Zone.choose` 复制 `0x2b8e0` 的选择关系：入口与首领候选数相等时共享索引，三类数量均相等时特殊房也共享；其余部分按原分支单独抽选。46 个 ZON、每个 3 种受控随机输入与 ARM 对照。读取存档不重新抽选。

选择结果用于入口出生点、首领完成判定、特殊房音乐，并保存入口/首领/特殊房索引和当前位置。房间移动仍沿原 DS 目标场景、目标入口编号；方向字段按 `0x2c464` 更新格坐标。本版恢复的是**原候选路线随机选择**，不是新造地图，也不宣称全部封路、特殊房调度和原地图界面完成。22 个可玩地下城的候选入口到对应首领已做 DS 图连通检查，幽暗密林两种入口均用实际移动/战斗输入打通。

启用另一入口时，发现 `83/4` 的原敌人出生点 `(437,312)` 超过移植版 FIE 高度 304。针对落在网格外的原出生点，选择最近可行走位置，避免不可达敌人和读档拒绝；网格内坐标保持原值。这是有记录的移植端边界适配。

- Campaign v4 追加 SP、技能等级和路线选择；DNB3 追加敌方特效位置、动画和命中状态。DNS4 剧情外层格式不变。
- 继续读取 Campaign v1/v2/v3、DNB1/DNB2；旧存档缺少 SP 历史时按当前等级/经验补算未消费 SP，这是迁移策略，不能恢复历史大额经验奖励中的全部 byte 截断差异。
- 旧版本正在播放的错误普通角色技能效果，载入后结束该次动作，保留 HP/MP/冷却、敌人和任务记录；不把旧 30024 的帧号硬套到 30032。
- `tests/fixtures/battle-v06.dnb` 由提交 `677b963` 的实际 Java 源码生成，保存于 41/3 正在释放旧鬼斩时；不含任何用户记录。

## 验证与后续

`tools/reverse/combat_rules_oracle.py` 显式执行原 ARM，生成 1,094 条技能等级、480 组基础伤害、120 组 XP/SP、138 组选路、800 组攻击选择、336 组攻击范围结果；普通测试只读提交的 CSV。哈希和替代调用见 `tests/fixtures/combat-rules-provenance.json`。随机数可控，算术与技能解码没有用 Java/Python 期望逻辑替换；攻击选择后的游走调用被隔离，不宣称已核验该部分。

测试覆盖：原版规则 55,768、核心 44,033、剧情 13,377、战斗 640、城镇/地下城 181、玩法 737、四种分辨率 Canvas/RMS 683 项。场景特效测试使用明确设置的首领场景状态；两条幽暗密林通关用真实输入与已获得的物品，不注入击杀结果。原有 69 主线节点仍是目标注入后的事务测试，不是全游戏人工实战通关。

已查看生产 Canvas 的 240×320、320×240 技能详情及落雷预兆/攻击帧。高分辨率与低分辨率触屏默认值保持。此次没有完成独立模拟器窗口的人工完整通关和听感对照。

下一步仍需按证据恢复：完整技能树及转职/被动、附加伤害和异常流水线、牛头王增益等其他行为类型、封路/特殊房与后期逐关实战。0.7 不标记为原版等价或最终版。
