# 0.8：职业目录、异常状态与首领行为

本版恢复职业成长、技能学习/绑定及更多战斗行为，**不是所有技能机制已经等价于原版**。完整目录与完整行为是两件事；下面分别记录。

## 已接入

- 原 `0x1400563 / 0x1400581` 五组目录、`0x140306d` 的75项动作映射。四个转职及四个觉醒身份；波动、武器技、血气、鬼神、通用分组。未转职22项，剑魂32项、鬼泣32项、狂战士35项、阿修罗33项（各目录含共有节点，不是相加后独立技能数）。原技能等级、SP、等级/前置技能/觉醒限制，中文菜单学习与1/3绑定。
- 423—462号四条转职/觉醒委托，保留原任务物品、金币、击杀、通关要求及交付NPC。转职重置技能、返还累计SP；觉醒保留已学等级。技能56对剑魂三段斩变体4→5的前置别名是适配处理，尚未逐条核验原生替换流程。
- `0x1402fa4` 职业属性表：每级力量/智力/体力/精神分别为 `[2,2,2,2] / [3,2,3,2] / [2,4,2,4] / [4,2,4,2] / [3,3,3,3]`。无装备和被动修正时HP每级31/44/31/57/49，MP每级16/26/37/21/24，再加20。觉醒沿用对应转职表。
- 所有目录内主动节点可加载原动作和前/后层特效。两个绑定技能的持续效果分别推进、判定、绘制并保存，施放第二个不会冻结第一个。普通攻击键误按在技能过程中不会把该次技能伤害参数换成普攻。
- 已消费的效果包括武器精通、暴击、强制取消、部分属性/速度/攻击增益、武器及首饰附加固定伤害、最大生命比例伤害、命中回血回蓝；部分技能与装备施加出血、灼烧、感电、冰冻、失明、减速等状态。持续伤害按原表计时，控制状态阻止移动/攻击/敌方行动。
- 首领/精英行为：原固定位置特效、召唤原房间怪物模板、治疗目标选择、自损、增益分发、四系持续光环、随机瞬移的26消失→可站立点检查→25出现。使用原描述参数、动画和特效；敌方速度和霸体增益实际参与战斗。验证样本含怪物411的群体速度/治疗、58的召唤、27的光环、56的瞬移，凯诺落雷继续保留。
- 新增27/35/36号地下城入口供职业试炼使用。死亡之塔原136—140场景的45层顺序、分层积分及每层10%HP/MP恢复已接入。任务条件17比较的是累计塔积分，不是连击数。下一层确认界面仍为移植适配，27/35入口中文名为临时描述名。

`j2me/tools/reverse/skills_status_oracle.py` 显式运行原ARM生成75组动作/特效分派、144组状态初始化、80组覆盖规则和72组职业HP/MP样本。普通测试只读已提交CSV，不从Java实现生成期望值。效应加载器捕获资源调用，不能据此证明高级技能的后续动作等价；成长样本将两项防具精通贡献隔离为0，不能据此宣称防具精通已恢复。其余替代调用及二进制哈希在 `skills-status-provenance.json`。

`SkillsStatusTest` 包含各职业节点学习、主动动作启动、施放中逐tick存读、两圈共存、状态跨房间、召唤/治疗/光环/瞬移。40个职业任务使用目标注入验证接取和交付事务，**不是四职业自然通关**。所有目录主动技能可以启动与续存，也不等于每个特殊机制都正确。现有主线、原音频/动画、旧存档和两条幽暗密林实际输入流程继续回归。四分辨率Canvas桌面适配器增加觉醒技能绑定和RMS验证；没有用这些结果替代真机完整通关。
